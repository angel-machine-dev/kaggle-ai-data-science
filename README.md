# Kaggle Learn: Data Science, AI & SQL Courses

A collection of Jupyter Notebooks (`.ipynb`) and coding exercises completed as part of my **Kaggle Learn** certifications.

## ✅ Completed Courses

* **[01-Python](./01-Python)** — Core syntax, functions, loops, list comprehensions, strings, dictionaries, and external libraries.
* **[02-Intro-to-Machine-Learning](./02-Intro-to-Machine-Learning)** — Data exploration, Decision Trees, model validation, underfitting/overfitting, and Random Forests.
* **[03-Pandas](./03-Pandas)** — DataFrames, indexing, grouping, sorting, missing values, and combining datasets.
* **[04-Data-Visualization](./04-Data-Visualization)** — Line charts, bar charts, heatmaps, scatter plots, and distributions with Seaborn.
* **[05-Intermediate-Machine-Learning](./05-Intermediate-Machine-Learning)** — Missing values, categorical variables, pipelines, cross-validation, and XGBoost.
